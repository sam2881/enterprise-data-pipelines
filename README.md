# enterprise-data-pipelines

Data pipelines for **data-engineering**.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Validate DAGs
python -c "from airflow.models import DagBag; db = DagBag('dags'); print(db.import_errors or 'OK')"

# Run tests
pytest tests/ -v
```
