## Medallion Architecture

| Layer | Purpose | Location |
|-------|---------|----------|
| **Bronze** | Raw data ingestion with audit columns | `gs://PROJECT-bronze/` |
| **Silver** | Cleaned, deduplicated, enriched data | `gs://PROJECT-silver/` |
| **Gold** | Aggregated data for analytics (BigQuery) | `gs://PROJECT-gold/` + BigQuery |

## CI/CD Pipeline

On merge to `main`:
1. **Validate** - Check DAG syntax with Airflow
2. **Security Scan** - Check for hardcoded secrets
3. **Deploy DAGs** - Sync to Composer's GCS bucket
4. **Deploy Spark** - Sync to gold bucket for Dataproc
5. **Notify** - Slack notification

## Required GCP Setup

### Secrets (GitHub Actions)
- `GCP_SA_KEY` - Service account JSON with Composer Admin role
- `GCP_PROJECT_ID` - Your GCP project ID
- `COMPOSER_LOCATION` - Composer region (e.g., `us-central1`)
- `SLACK_WEBHOOK_URL` - (Optional) For notifications

### GCS Buckets
```bash
gsutil mb gs://${PROJECT_ID}-bronze
gsutil mb gs://${PROJECT_ID}-silver
gsutil mb gs://${PROJECT_ID}-gold
gsutil mb gs://${PROJECT_ID}-temp  # For BigQuery staging
```

### Composer Environment
```bash
gcloud composer environments create data-pipelines-dev \
  --location=us-central1 \
  --image-version=composer-2.5.0-airflow-2.6.3
```

## Manual Deployment

```bash
# Deploy DAGs manually
gsutil -m rsync -r -d dags/ gs://YOUR-COMPOSER-BUCKET/dags/

# Deploy Spark jobs
gsutil -m rsync -r -d spark/ gs://${PROJECT_ID}-gold/spark/
```
